# FLOW — An Interactive Study of Motion

A generative visual experiment exploring motion, distortion, and interaction.

Built for the **Dodo Payments Design Engineer Assignment**.

## Overview

FLOW is an interactive visual toy built with React, TypeScript, and Paper Shaders. It explores how pointer movement and user input influence shader-driven visuals, turning an abstract visual field into a responsive experience.

The focus is on creating a simple, intuitive interaction where movement changes the visual and each input feels immediate.

## Features

- **Interactive shader visuals** — Explore generative effects through direct pointer interaction.
- **Motion-responsive effects** — Influence the visual field through pointer movement.
- **Interactive disturbances** — Trigger visual changes with clicks.
- **Sound interaction** — Audio or sound effects that respond to user interaction.
- **Capture visual** — Take a picture of the current visual and save it as an image.
- **Multiple visual styles** — Experiment with different shader-based appearances.
- **Minimal interface** — A dark, distraction-free environment focused on the visual experience.

## Tech Stack

- React
- TypeScript
- Vite
- Paper Shaders
- CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/ashubrothaaa007/flowshaders.git
cd flowshaders
npm install
npm run dev
```
